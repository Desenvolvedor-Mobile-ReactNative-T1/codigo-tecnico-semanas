## Como executar

### Exercícios em JavaScript

Para executar os arquivos de JavaScript, use um terminal na pasta da semana correspondente:

```bash
cd semana-02
node exercicio-01.js
```

### Exercícios com `prompt-sync`

As pastas `semana-03` e `semana-05` usam `prompt-sync` para leitura de entrada no terminal. Você precisa instalar o pacote dentro da pasta da semana que contém o `package.json`.

Para instalar em `semana-03`:

```bash
cd semana-03
npm install prompt-sync
```

Para instalar em `semana-05`:

```bash
cd semana-05
npm install prompt-sync
```

Depois de instalar, execute os exercícios normalmente a partir da pasta correspondente:

```bash
node exercicio-01.js
```

### Página HTML

Abra `semana-01/index.html` no navegador para visualizar o conteúdo do primeiro módulo.

## Objetivo

O objetivo deste projeto é praticar lógica de programação, estrutura de dados, manipulação de DOM básica e interação no terminal usando JavaScript.

## Observações

- O projeto está organizado por semana para facilitar o acompanhamento do estudo.
- Os arquivos `package.json` servem apenas para declarar dependências de terminal nos exercícios.
- Você pode adaptar e expandir os exercícios com novos desafios.
